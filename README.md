# Netnoddy's Blog

This blog is built with Jekyll and GitHub Pages. Write each post as a Markdown file in `_posts`; pushing it to the `main` branch automatically rebuilds and publishes the site.

In the repository's **Settings > Pages**, set the publishing source to the `main` branch and `/(root)` if it is not already configured.

## Write a post

Create a file named `_posts/YYYY-MM-DD-short-title.md`, for example `_posts/2026-10-24-first-post.md`:

```markdown
---
layout: default
title: "My first post"
date: 2026-10-24 09:00:00 -0700
---

Write the post here using Markdown.
```

Commit and push the file to `main`. GitHub Pages will publish it automatically; the newest posts appear on the homepage.
